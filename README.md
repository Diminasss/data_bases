# Лабораторные и курсовая работа по базам данных

Учебный репозиторий по проектированию, реализации и администрированию реляционных баз данных. Первая часть построена вокруг MySQL и информационной системы железнодорожной станции. Во второй части показаны миграция данных, интеграция СУБД с Python и визуализация результатов. Итоговая курсовая объединяет SQL-схему и настольный PyQt5-клиент.

## Как работать с репозиторием

Каждый каталог содержит собственный README с назначением файлов и порядком запуска. SQL-работы можно открывать в MySQL Workbench или клиенте PostgreSQL в зависимости от лабораторной. Для Python-проектов создайте отдельное виртуальное окружение внутри нужного каталога и установите его `requirements.txt`.

Параметры подключения к базе задаются либо в `.env`, либо непосредственно в учебном скрипте — точный формат приведён в README соответствующей работы.
