# Лабораторная работа №1. Установка и настройка MySQL

## Цель работы

Установить MySQL Server и MySQL Workbench, настроить локальный сервер баз данных и проверить возможность подключения к нему.

## Содержание

В отчёте рассмотрены установка компонентов MySQL, первичная настройка сервера и создание подключения в MySQL Workbench. Эта работа подготавливает окружение для последующих лабораторных, в которых проектируются и реализуются базы данных.
