# Лабораторная работа №8. Основы администрирования MySQL

## Цель работы

Освоить создание пользователей и ролей MySQL, а также выдачу минимально необходимых прав для разных участников информационной системы.

## Содержание

В отчёте рассмотрены:

- создание учётных записей операторов системы;
- назначение паролей и ограничение источника подключения;
- выдача прав `SELECT`, `INSERT` и `UPDATE` на отдельные таблицы и столбцы;
- создание ролей и назначение роли по умолчанию;
- проверка доступа для администратора, ремонтной службы, медслужбы, диспетчеров и пассажира.

Примеры команд включают `CREATE USER`, `CREATE ROLE`, `GRANT` и `SET DEFAULT ROLE` для базы `train_station`.
