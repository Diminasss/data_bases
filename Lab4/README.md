# Лабораторная работа №4. Физическая реализация базы данных

## Цель работы

Развернуть спроектированную базу железнодорожной станции на MySQL Server, заполнить её тестовыми данными и проверить полученную структуру.

## Что реализовано

- схема `Train_Station` из 11 связанных таблиц;
- первичные и внешние ключи;
- тестовые записи для станций, подразделений, сотрудников, поездов, рейсов, пассажиров и билетов;
- служебные запросы для просмотра таблиц и данных.

## Файлы

| Файл | Назначение |
| --- | --- |
| [`SCRIPT.sql`](SCRIPT.sql) | Создание схемы, таблиц и ограничений |
| [`Fill in the table.sql`](<Fill in the table.sql>) | Заполнение таблиц тестовыми данными |
| [`SHOW_DB.sql`](SHOW_DB.sql) | Просмотр объектов и содержимого базы |
| [`Лаб4_отчёт.pdf`](Лаб4_отчёт.pdf) | Отчёт по работе |

## Порядок запуска

1. Подключитесь к MySQL 8.0 или новее.
2. Выполните `SCRIPT.sql`.
3. Выполните `Fill in the table.sql`.
4. Используйте `SHOW_DB.sql` для проверки структуры и данных.

## Результат

Логическая модель из предыдущей лабораторной преобразована в физическую базу `Train_Station`, готовую для процедур, функций и триггеров.
